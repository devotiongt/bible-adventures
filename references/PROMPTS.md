Always attach the style image (the scene of Noah with the ark) and ask it to keep that style.
Save the images in this folder (`references/`) with the name each prompt gives.

What matters in all of them: **orthographic view (no perspective), same scale between views,
feet aligned on the same line, plain white background, no shadows or scenery.**
